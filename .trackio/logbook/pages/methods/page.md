# Methods

Exact full-batch ridge GD is evolved by diagonalizing X Xᵀ, while null-space coordinates decay by 1-eta*lambda. Five tests compare the spectral state to 25 explicit GD steps, check integer threshold semantics, validate exact population loss against 120,000 fresh Gaussian points, test Eq. (8), and require bitwise deterministic generation. Scope is the three scored ridge claims; nonlinear extensions, random features, and noisy-label experiments are excluded. The Gaussian distribution is unbounded, so this is the paper’s finite-sample specialization rather than a proof for arbitrary bounded feature maps.
